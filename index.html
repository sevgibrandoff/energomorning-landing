Лендинг ещё не залит сюда

Это временная заглушка. Актуальный код лендинга «Дыхательный практикум «Основы»» сейчас живёт в конструкторе GetCourse и последний раз редактировался прямо в чате (без сохранения в git) — целиком в этот репозиторий он ещё не попадал, в основном из-за больших фотографий, зашитых в код как base64.

Чтобы включить его сюда: скопируйте актуальный код страницы прямо из GetCourse (Настройки сайта → страница лендинга → код страницы → скопировать всё) и пришлите его Claude в этом репозитории — он заменит этот файл на реальный лендинг и запушит в git, после чего сайт обновится на GitHub Pages автоматически.

Страница «Спасибо за оплату» уже перенесена дословно: thanks.html.

Подробности проекта — в docs/CHANGELOG.md.
