# Changelog — «Дыхательный практикум «Основы»»

Восстановлено из истории переписки. Даты — это порядок правок в диалоге, не календарные
даты работы (если нужны реальные даты — фиксировать их в новом репозитории по коммитам).

## Лендинг

1. **Смена потока 1 → 2**
   - `<title>`, `<meta name="description">`, hero-бейдж, заголовок перед прайсингом,
     финальный CTA: «17 августа» → «14 сентября», «9 августа» → «7 сентября»
   - Текст «Раннее бронирование действует только до …» → «Льготная покупка действует
     только до …»
   - В шапку/бейдж добавлено «2 поток»: `«Первая ступень · 2 поток»`,
     `«Старт 2 потока — 14 сентября»`

2. **Исправление видимости блока «Это не работает / Почему?»**
   - Причина: тёмный фон секции `.contrast` и светлый текст в ней не применялись на
     реальном сайте GetCourse (см. README, п. 4.2)
   - Исправление: фон/цвет продублированы инлайн-стилями с `!important` на самой
     секции, на карточках-крестиках и на блоке «Почему?»
   - Заодно: шрифт текста внутри блока увеличен (14.5px → 15.5px) и сделан ярче
     (более светлые/насыщенные оттенки кремового и золотистого)

3. **Увеличение самого мелкого шрифта на странице**
   - `.eyebrow` и `.price-tag`: `font-size:12px` → `14px`

4. **Анимации + мобильная версия**
   - `.pill-date` — пульсация даты старта в hero
   - `.deadline-badge` — пульсирующий бейдж вокруг даты дедлайна льготной цены
   - `.btn-pulse` — пульсирующее свечение на кнопках «Забронировать место» /
     «Забронировать» (hero + финальный CTA), гасится на hover
   - `.mobile-sticky-cta` — закреплённая кнопка «Забронировать место» внизу экрана
     на мобильных (≤640px)
   - Кнопка в hero на мобильных — full width; чуть увеличены `.pill` на мобильных

5. **Тот же баг видимости повторно найден и исправлен ещё в 3 местах**
   - «Кто тебя ведёт?» (`.about-mentor`): фон секции, `.mentor-name`, `.mentor-facts`,
     `.mentor-quote` — инлайн-цвета с `!important`
   - Финальный CTA (`.final-cta`): фон/цвет секции — инлайн с `!important`
   - Футер (`<footer>`): фон/цвет — инлайн с `!important` (превентивно, жалоб не было)

6. **Финальный CTA — выравнивание**
   - `.final-cta` вёрстка съезжала влево вместо центра (та же причина — правило
     `text-align:center` было только в классе и не применялось)
   - Исправление: `text-align:center !important` добавлен инлайн на секцию;
     у параграфа продублированы `max-width:540px;margin:0 auto`

## Известные пробелы в этой копии (см. README, раздел 7)

- `landing.html` в этом репозитории **не является дословной копией** последней версии
  на GetCourse — файл редактировался кусками на протяжении диалога, включая фотографии
  в base64, которые целиком в чат не попадали. Нужно забрать финальный код прямо из
  GetCourse и заменить плейсхолдер.
- В `thanks_page.html` вместо реального base64 шрифта `Dance Partner` стоит плейсхолдер
  `PASTE_DANCE_PARTNER_FONT_BASE64_HERE` — сам блоб (~65 КБ нечитаемого текста) не
  копировался вручную из диалога во избежание риска побитово испортить файл шрифта.
  Взять его из последней рабочей версии на сайте (тот же кусок кода есть и в лендинге).
