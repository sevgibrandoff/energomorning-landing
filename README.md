# ЭнергоУтро — Дыхательный практикум «Основы»

Лендинг и страница «Спасибо за оплату» для практикума Ксении Зубановой. Репозиторий
отделён от документации Euro Energy — здесь только этот проект.

## Структура

- `index.html` — главный лендинг (сейчас заглушка, см. ниже — актуальный код нужно
  забрать из GetCourse)
- `thanks.html` — страница «Спасибо за оплату» (перенесена дословно, актуальна)
- `docs/CHANGELOG.md` — история правок, факты о проекте (потоки, даты, цены, найденные
  и исправленные баги вёрстки в GetCourse)

## Как публикуется сайт

Через **GitHub Pages**: любой пуш в ветку `main` автоматически обновляет сайт — никаких
отдельных команд деплоя не нужно.

**Разовая настройка (сделать один раз в веб-интерфейсе GitHub):**
1. Repository → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, папка **/ (root)**
4. Save

После этого сайт откроется по адресу `https://sevgibrandoff.github.io/energomorning-landing/`
(обычно в течение 1–2 минут после первого пуша).

## Подключение своего домена/поддомена

1. В репозитории создать файл `CNAME` (без расширения) с одной строкой — именем вашего
   домена, например:
   ```
   new.energomorning.ru
   ```
2. У регистратора домена (или там, где сейчас настроен DNS для energomorning.ru — это
   может быть панель GetCourse, если они дают доступ к DNS-записям) добавить запись:
   - Тип **CNAME**
   - Имя: поддомен, который используете (например `new`)
   - Значение: `sevgibrandoff.github.io`
3. Подождать применения DNS (обычно от 10 минут до нескольких часов).
4. В Settings → Pages репозитория появится поле "Custom domain" — вписать туда тот же
   домен и включить "Enforce HTTPS", когда появится доступно.

Если домен зарегистрирован именно через GetCourse как регистратора и в личном кабинете
нет доступа к редактированию DNS-записей (A/CNAME/TXT) — этот способ не сработает, тогда
нужно либо просить GetCourse дать доступ к DNS, либо переносить регистрацию домена к
другому регистратору.
